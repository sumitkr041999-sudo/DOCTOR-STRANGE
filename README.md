> Note: The agent is hosted in a Microsoft 365 account. Opening it requires a company sign-in and access shared by the owner.

## Description
Doctor Strange is a Microsoft Copilot agent that gives quick, easy-to-understand help with health-related questions, including medicines, hospitals and general medical guidance. It also helps with general queries and urgent needs.

## Problem it solves
People often struggle to find clear health information quickly. This agent gives simple answers in a friendly conversation, so users get first-level guidance without searching many websites.

## AI/ML technologies and tools used
- Microsoft 365 Copilot / Copilot Studio (Agent Builder)
- Generative AI (large language model)
- Prompt engineering (custom instructions for role and tone)
- Conversational AI

## How it works
The user starts a chat and the agent greets them by name, then answers based on its instructions.

Example:
- **User:** Hi, I am Sumit Kumar
- **Agent:** Hello Sumit Kumar! Nice to meet you! How can I help you today? If it's related to health, medicines, hospitals, or medical guidance, I'm here for that.
